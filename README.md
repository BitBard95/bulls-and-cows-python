# Bulls and Cows - Python

A terminal-based number guessing game where the player has to guess a 4-digit number with unique digits.
Built to practice Python basics like loops, conditionals, input validation, and logic comparison.




The Bulls and Cows game is a classic code-breaking game where a player tries to guess a secret number, and after each guess, they receive feedback in the form of:
	•	Bulls 🐂 – the number of digits that are correct and in the right position.
	•	Cows 🐄 – the number of digits that are correct but in the wrong position.

⸻

✅ Example Gameplay:

Let’s say the secret number is 4271.
	•	You guess 1234
	•	Bulls = 1 (The “2” is in the right place)
	•	Cows = 2 (The “1” and “4” are correct digits but in wrong positions)

⸻

💡 Rules:
	1.	The secret number usually has 4 digits, all different.
	2.	The player makes repeated guesses.
	3.	After each guess, the number of bulls and cows is returned.
	4.	The goal is to get 4 bulls (i.e., guess the number exactly).
